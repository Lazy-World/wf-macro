# /notes — changelog entry

Один блок, два адресата: `[USERS]` — те, кто пользуется макросами, `[GIT]` — commit-сообщение.

---

## Phase 0 — Scope (bash, 0 агентов)

```bash
git status --short
git diff --stat HEAD
git ls-files --others --exclude-standard
git describe --tags --exact-match 2>/dev/null || date +%F
```

Пустой `$ARGUMENTS` → uncommitted (`git diff HEAD` + untracked). Непустой → range (`v1.1.0..HEAD`, `main...HEAD`): `git diff $ARGUMENTS`, `git log $ARGUMENTS`.

Шапка записи — тег, если конец диапазона ровно на теге (`git describe --tags --exact-match`), иначе дата: uncommitted — сегодня, range — `git log -1 --format=%cs <конец диапазона>`.

Если изменений нет — сообщи (uncommitted: «Нет незакоммиченных изменений. Для готовых коммитов передай range, напр. `/notes v1.1.0..HEAD`»; range: «В диапазоне изменений нет») и остановись.

`changelog.txt` и `.claude/cache/` в scope не входят. Сам `.claude/` — инструменты, не пользовательская функциональность.

Читай сам diff. Если он больше ~500 строк — `--stat`, затем по файлам (`git diff <range> -- <path>`), начиная с `lib/` и `scripts/`. Новые untracked-файлы читай целиком, если они небольшие; `.md` — только заголовки. Для range читай и тела коммитов (`git log --format='%h %s%n%b'`), но в запись идёт то, что сделал код, а не пересказ тел.

Каждое утверждение — только то, что видно в прочитанном: без «все», «для каждого», «теперь всегда», если этого не видно в коде. git руками не трогать: без checkout, commit, stash.

## Phase 1 — Тема

Короткое русское слово, ≤ 15 символов. Предпочтительно из списка:

`фиксы · рефакторинг · новый макрос · UI · библиотеки · joiner · настройки · скорость · документация · инструменты`

---

## Phase 2 — `[USERS]`

Для тех, кто пользуется макросами.

- Русский, прошедшее время, безлично: Оптимизирована, Исправлена, Добавлена.
- Только видимое пользователю: новый макрос, изменённые клавиши и настройки, исправления, ощутимая скорость и точность.
- Внутренние рефакторинги и архитектуру **пропускать**. Весь релиз внутренний → одна строка: `Оптимизирована внутренняя архитектура макросов.`
- Без имён классов, функций, файлов и путей.
- 1–5 буллетов, близкое сливать.

## Phase 3 — `[GIT]`

Для commit-сообщения.

- Русский, прошедшее время, безлично.
- Одно предложение на буллет, ~80 символов.
- **ЧТО** изменилось на уровне поведения и архитектуры, не **КАК**. Без сигнатур и путей.
- 3–8 буллетов. Порядок: фичи → улучшения → баг-фиксы.

## Phase 4 — Запись + уборка (один Bash-вызов)

```bash
mkdir -p .claude/cache/notes
cat > .claude/cache/notes/entry.txt <<'EOF'
<YYYY-MM-DD или тег> - <theme>

[USERS]
- ...

[GIT]
- ...
EOF
entry=.claude/cache/notes/entry.txt
head -1 "$entry" | grep -qE '^([0-9]{4}-[0-9]{2}-[0-9]{2}|v?[0-9]+\.[0-9]+\.[0-9]+[0-9A-Za-z.+-]*) - .+$' || { echo 'ОТКАЗ: шапка не в формате "дата/тег - тема"'; rm -rf .claude/cache/notes; exit 1; }
grep -q '^\[USERS\]$' "$entry" && grep -q '^\[GIT\]$' "$entry" || { echo 'ОТКАЗ: нет разделов [USERS] / [GIT]'; rm -rf .claude/cache/notes; exit 1; }
LC_ALL=C.UTF-8 grep -qP '[\x{1F000}-\x{1FAFF}\x{2190}-\x{2BFF}\x{00A9}\x{00AE}\x{2122}\x{FE0F}\x{200D}]' "$entry" && { echo 'ОТКАЗ: emoji, галочки или символьные значки'; rm -rf .claude/cache/notes; exit 1; }
cat "$entry" >> changelog.txt
rm -rf .claude/cache/notes
```

`changelog.txt` — только дописывание (`>>`), редактировать его руками нельзя и в git он не добавляется, если пользователь не попросил. `ОТКАЗ` → исправь блок и повтори ту же команду. Файла нет — норма: команда создаст его. Прервался после записи — всё равно `rm -rf .claude/cache/notes`.

## Примеры

```
2026-10-25 - новый макрос

[USERS]
- Добавлен макрос Cyte-08: смарт-режим по иконке элемента у счётчика патронов.
- Добавлен спам 4-й способности, пока зажата её клавиша.

[GIT]
- Добавлен макрос Cyte-08 с двумя режимами работы.
- Добавлена проверка пикселя иконки элемента патронов.
- Настройки макроса вынесены в отдельный cfg.
```

```
2026-11-19 - рефакторинг

[USERS]
- Оптимизирована внутренняя архитектура макросов.

[GIT]
- Упрощена библиотека интерфейса: удалён шаблонный класс статусного окна.
- Общее начало макросов вынесено в один подключаемый файл.
- Групповые клавиши переведены с меток на функции.
```
